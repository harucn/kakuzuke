# host-screen Specification

## Purpose

司会が会場のプロジェクタに投影し、問題を順に進めて正解と解説を発表するための画面を定める。

## Requirements

### Requirement: 問題の表示
司会画面は現在の問題について、問題番号と総問題数、問題名、説明、各選択肢のラベルと写真を表示しなければならない（MUST）。新しいタブで開いたときは第 1 問を表示する。

#### Scenario: 新しいタブで開いた直後は第 1 問を表示する
- **WHEN** 新しいタブで司会画面を開く
- **THEN** 第 1 問の問題名・説明・全選択肢のラベルと写真、および「1 / 総問題数」が表示される

#### Scenario: 正解発表前は正解情報を表示しない
- **WHEN** 問題を表示し、まだ正解発表をしていない
- **THEN** 正解の印、順位、銘柄、価格、解説はどれも表示されない

### Requirement: 前後の問題への移動
司会画面は前の問題・次の問題へ移動する操作を、画面内のボタンで提供しなければならない（MUST）。第 1 問では前へ、最終問では次へは操作できない。移動先の問題は正解発表前の状態で表示する。

#### Scenario: 次へで次の問題を表示する
- **WHEN** 第 1 問で「次へ」を押す
- **THEN** 第 2 問が正解発表前の状態で表示される

#### Scenario: 前へで前の問題を表示する
- **WHEN** 第 2 問で「前へ」を押す
- **THEN** 第 1 問が正解発表前の状態で表示される

#### Scenario: 第 1 問では前へを操作できない
- **WHEN** 第 1 問を表示している
- **THEN** 「前へ」は無効で、押しても第 1 問のままである

#### Scenario: 最終問では次へを操作できない
- **WHEN** 最終問を表示している
- **THEN** 「次へ」は無効で、押しても最終問のままである

#### Scenario: 正解発表後に移動して戻ると発表前に戻る
- **WHEN** 第 1 問で正解発表をしてから「次へ」、続けて「前へ」を押す
- **THEN** 第 1 問が正解発表前の状態で表示される

### Requirement: 再読み込みで同じ問題に戻る
同じタブで司会画面を再読み込みしたとき、司会画面は再読み込み前に表示していた問題を、正解発表前の状態で表示しなければならない（MUST）。

#### Scenario: 第 3 問で再読み込みすると第 3 問に戻る
- **WHEN** 第 3 問を表示している司会画面を再読み込みする
- **THEN** 第 3 問が正解発表前の状態で表示される

#### Scenario: 正解発表後に再読み込みすると発表前の状態に戻る
- **WHEN** 第 2 問で正解発表をしてから司会画面を再読み込みする
- **THEN** 第 2 問が正解発表前の状態で表示される

#### Scenario: 問題数が減った後の再読み込みでは範囲内の問題を表示する
- **WHEN** 第 5 問を表示した後、問題数が 3 問のセットがデプロイされ、同じタブで再読み込みする
- **THEN** 最終問である第 3 問が表示される

### Requirement: pick の正解発表
`pick` の問題で正解発表をすると、司会画面は `rank: 1` の選択肢に「正解」の印を付け、全選択肢の銘柄と価格、正解ラベルと解説を表示しなければならない（MUST）。正解の選択肢は色だけでなく文字の印でも区別できなければならない（MUST）。

#### Scenario: pick で正解の選択肢に正解の印が付く
- **WHEN** 選択肢 B が `rank: 1` の `pick` の問題で「正解発表」を押す
- **THEN** 選択肢 B に「正解」の文字の印が表示され、選択肢 A には表示されない

#### Scenario: pick の正解発表で全選択肢の銘柄と価格を表示する
- **WHEN** `pick` の問題で「正解発表」を押す
- **THEN** すべての選択肢にそれぞれの銘柄と価格が表示される

#### Scenario: pick の正解発表で正解ラベルと解説を表示する
- **WHEN** 選択肢 B が `rank: 1` の `pick` の問題で「正解発表」を押す
- **THEN** 「正解は B」とその問題の解説が表示される

### Requirement: order の正解発表
`order` の問題で正解発表をすると、司会画面は全選択肢に順位・銘柄・価格を表示し、`rank: 1` の選択肢に「正解」の印を付け、rank の昇順に並べたラベル列と解説を表示しなければならない（MUST）。

#### Scenario: order の正解発表で 1 位の選択肢に正解の印が付く
- **WHEN** A、B、C の `rank` が 1、3、2 の `order` の問題で「正解発表」を押す
- **THEN** 選択肢 A に「正解」の文字の印が表示され、B と C には表示されない

#### Scenario: order の正解発表で全選択肢に順位を表示する
- **WHEN** A、B、C の `rank` が 1、3、2 の `order` の問題で「正解発表」を押す
- **THEN** A に 1 位、B に 3 位、C に 2 位が、それぞれの銘柄と価格とともに表示される

#### Scenario: order の正解発表で正解の並びと解説を表示する
- **WHEN** A、B、C の `rank` が 1、3、2 の `order` の問題で「正解発表」を押す
- **THEN** 「正解は A → C → B」とその問題の解説が表示される

### Requirement: 正解発表の再演出
正解発表後に再び正解発表を操作すると、司会画面は正解発表の演出（紙吹雪と正解の印の点滅）を最初からもう一度再生しなければならない（MUST）。表示する正解情報（正解の印・順位・銘柄・価格・解説）は変えてはならない（MUST NOT）。動きを減らす OS の設定（reduced motion）が有効なときは、演出を再生しない。

#### Scenario: 正解発表をもう一度押すと演出を再生する
- **WHEN** 正解発表をした問題で、もう一度「正解発表」を押す
- **THEN** 紙吹雪と正解の印の点滅が最初から再生される

#### Scenario: 正解発表をもう一度押しても正解情報は変わらない
- **WHEN** 正解発表をした問題で、もう一度「正解発表」を押す
- **THEN** 正解の印・順位・銘柄・価格・解説は 1 回目の正解発表後と同じである

#### Scenario: reduced motion が有効なときは演出を再生しない
- **WHEN** reduced motion が有効な環境で「正解発表」を押す
- **THEN** 紙吹雪と点滅は再生されず、正解情報は表示される

### Requirement: キーボード操作
司会画面はキーボードとプレゼン用リモコンで操作できなければならない（MUST）。→ と PageDown は次へ、← と PageUp は前へ、Space と Enter は正解発表に対応する。

#### Scenario: → キーで次の問題へ進む
- **WHEN** 第 1 問で → キーを押す
- **THEN** 第 2 問が表示される

#### Scenario: PageDown キーで次の問題へ進む
- **WHEN** 第 1 問で PageDown キーを押す
- **THEN** 第 2 問が表示される

#### Scenario: ← キーで前の問題へ戻る
- **WHEN** 第 2 問で ← キーを押す
- **THEN** 第 1 問が表示される

#### Scenario: PageUp キーで前の問題へ戻る
- **WHEN** 第 2 問で PageUp キーを押す
- **THEN** 第 1 問が表示される

#### Scenario: Space キーで正解発表する
- **WHEN** 正解発表前の問題で Space キーを押す
- **THEN** その問題の正解発表が表示される

#### Scenario: Enter キーで正解発表する
- **WHEN** 正解発表前の問題で Enter キーを押す
- **THEN** その問題の正解発表が表示される

### Requirement: 全画面表示
司会画面は画面内の操作で全画面表示に切り替え、同じ操作で元に戻せなければならない（MUST）。ブラウザが全画面表示を拒否しても、画面はそのまま操作を続けられなければならない（MUST）。

#### Scenario: 全画面ボタンで全画面表示になる
- **WHEN** 通常表示で全画面ボタンを押す
- **THEN** 司会画面が全画面表示になる

#### Scenario: 全画面表示中に全画面ボタンで元に戻る
- **WHEN** 全画面表示中に全画面ボタンを押す
- **THEN** 通常表示に戻る

#### Scenario: 全画面表示が拒否されても操作を続けられる
- **WHEN** ブラウザが全画面表示を拒否する環境で全画面ボタンを押す
- **THEN** エラーで止まらず、前へ・次へ・正解発表をそのまま操作できる

### Requirement: 投影時の可読性
司会画面は 16:9 の領域に収まるよう配置し、明るい部屋のプロジェクタで読めるコントラストでなければならない（MUST）。問題名・説明・解説の文字と背景のコントラスト比は 4.5:1 以上とする。

#### Scenario: 1920×1080 の表示で全要素が 1 画面に収まる
- **WHEN** 1920×1080 のビューポートで 3 択の問題の正解発表をする
- **THEN** 問題名・全選択肢・解説・操作ボタンがスクロールなしで表示される

#### Scenario: 文字と背景のコントラスト比が 4.5:1 以上である
- **WHEN** 司会画面の問題名・説明・解説の文字色と背景色のコントラスト比を測る
- **THEN** どれも 4.5:1 以上である
