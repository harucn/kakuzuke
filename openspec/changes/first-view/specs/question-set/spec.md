# Spec Delta

## MODIFIED Requirements

### Requirement: 問題セットのデータ形式
問題セットは会のタイトルと、1 つ以上の問題を出題順に並べたものを持たなければならない（MUST）。タイトルは空にできない。各問題は出題形式 `mode`（`pick` または `order`）、問題名、説明、解説、選択肢 2〜3 個を持つ。各選択肢は写真 `image`、順位 `rank`、銘柄 `name`、価格 `price` を持つ。選択肢のラベルは作者が書かず、並び順から決まる。

#### Scenario: 正しい問題セットは検証を通る
- **WHEN** タイトルと、`pick` の 2 択問題と `order` の 3 択問題を含む、全項目が揃った問題セットを検証する
- **THEN** 検証は成功する

#### Scenario: タイトルがない問題セットは検証に失敗する
- **WHEN** タイトルを書いていない問題セットを検証する
- **THEN** 検証は失敗し、タイトルの項目がエラーで示される

#### Scenario: タイトルが空の問題セットは検証に失敗する
- **WHEN** タイトルが空文字または空白だけの問題セットを検証する
- **THEN** 検証は失敗し、タイトルの項目がエラーで示される

#### Scenario: 問題が 0 件の問題セットは検証に失敗する
- **WHEN** 問題を 1 件も含まない問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: 未知の mode は検証に失敗する
- **WHEN** `mode` が `pick` でも `order` でもない問題を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題がエラーで示される

#### Scenario: 問題名・説明・解説が空の問題は検証に失敗する
- **WHEN** 問題名、説明、解説のいずれかが空文字または空白だけの問題を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題と項目がエラーで示される

#### Scenario: 写真・銘柄・価格が空の選択肢は検証に失敗する
- **WHEN** 写真・銘柄・価格のいずれかが空文字または空白だけの選択肢を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題・選択肢と項目がエラーで示される

#### Scenario: 複数の誤りはまとめて報告される
- **WHEN** rank の重複、写真の欠落、空の解説を 1 つずつ含む問題セットを検証する
- **THEN** 検証は失敗し、3 件すべてがエラーで示される

### Requirement: 問題名と説明に正解情報を含めない
問題セットのタイトルと、各問題の問題名と説明は、問題セット内のどの選択肢の銘柄・価格の文字列も、どの問題の解説の文字列も含んではならない（MUST NOT）。タイトル・問題名・説明は参加者に公開されるため。

#### Scenario: 説明に価格を含む問題は検証に失敗する
- **WHEN** 説明が「1本 5万円のワインと…」で、選択肢の価格に「1本 5万円」がある問題を含む問題セットを検証する
- **THEN** 検証は失敗し、該当する問題と含まれていた文字列がエラーで示される

#### Scenario: 問題名に銘柄を含む問題は検証に失敗する
- **WHEN** 問題名に、いずれかの選択肢の銘柄と同じ文字列を含む問題セットを検証する
- **THEN** 検証は失敗する

#### Scenario: タイトルに銘柄を含む問題セットは検証に失敗する
- **WHEN** タイトルに、いずれかの選択肢の銘柄と同じ文字列を含む問題セットを検証する
- **THEN** 検証は失敗し、タイトルの項目と含まれていた文字列がエラーで示される

#### Scenario: 正解情報を含まない問題名と説明は検証を通る
- **WHEN** タイトルと説明が「高いワインはどちら？」のように銘柄・価格・解説の文字列を含まない問題セットを検証する
- **THEN** この規則の検証は成功する

### Requirement: 参加者向けの公開形
システムは問題セットから、タイトルと、各問題の出題形式・問題名・説明と、各選択肢のラベル・写真だけを含む公開形を作らなければならない（MUST）。公開形は `rank`・`name`・`price`・解説を含んではならない（MUST NOT）。

#### Scenario: 公開形は rank・name・price を含まない
- **WHEN** 問題セットを公開形に変換する
- **THEN** どの選択肢にも `rank`、`name`、`price` の項目が存在しない

#### Scenario: 公開形は解説を含まない
- **WHEN** 問題セットを公開形に変換する
- **THEN** どの問題にも解説の項目が存在しない

#### Scenario: 公開形は出題順と表示項目を保つ
- **WHEN** 3 問の問題セットを公開形に変換する
- **THEN** 公開形は元と同じタイトルと、同じ順の 3 問を持ち、各問題の出題形式・問題名・説明と、各選択肢のラベル・写真は元の値と一致する
