# Spec Delta

## ADDED Requirements

### Requirement: タイトル画面
参加者画面は第 1 問の前に、問題セットのタイトル、「全 N 問」（N は総問題数）、「はじめる」ボタンだけを表示するタイトル画面を持たなければならない（MUST）。開いた直後はタイトル画面を表示する。遊び方の説明は表示せず、操作しない限り第 1 問へは進まない。

#### Scenario: 開いた直後はタイトル画面を表示する
- **WHEN** 参加者画面を開く
- **THEN** 問題セットのタイトル、「全 N 問」、「はじめる」ボタンが表示され、問題は表示されない

#### Scenario: 操作しなければタイトル画面のまま
- **WHEN** 参加者画面を開き、何も操作せずに待つ
- **THEN** タイトル画面のままである

#### Scenario: はじめるで第 1 問を表示する
- **WHEN** タイトル画面で「はじめる」を押す
- **THEN** 第 1 問が表示される

#### Scenario: タイトル画面に正解情報を表示しない
- **WHEN** タイトル画面を表示する
- **THEN** 正解の印・順位・銘柄・価格・解説はどれも表示されない

### Requirement: 問題画面の表示
参加者画面は現在の問題について、問題番号と総問題数、問題名、説明、各選択肢のラベルと写真を表示しなければならない（MUST）。

#### Scenario: 第 1 問を問題番号つきで表示する
- **WHEN** タイトル画面から第 1 問へ進む
- **THEN** 第 1 問の問題名・説明・全選択肢のラベルと写真、および「1 / 総問題数」が表示される

#### Scenario: 3 択の問題で 3 つの選択肢を表示する
- **WHEN** 選択肢が 3 個の問題を表示する
- **THEN** A、B、C の 3 つの選択肢がラベルと写真つきで表示される

### Requirement: 前後の画面への移動
参加者画面は前の問題・次の問題へ移動する操作を提供しなければならない（MUST）。第 1 問の前はタイトル画面である。最終問では次へは操作できない。参加者画面の移動は司会画面の状態と連動しない。

#### Scenario: 次へで次の問題を表示する
- **WHEN** 第 1 問で「次へ」を押す
- **THEN** 第 2 問が表示される

#### Scenario: 前へで前の問題を表示する
- **WHEN** 第 2 問で「前へ」を押す
- **THEN** 第 1 問が表示される

#### Scenario: 第 1 問で前へを押すとタイトル画面に戻る
- **WHEN** 第 1 問で「前へ」を押す
- **THEN** タイトル画面が表示される

#### Scenario: 最終問では次へを操作できない
- **WHEN** 最終問を表示している
- **THEN** 「次へ」は無効で、押しても最終問のままである

## REMOVED Requirements

### Requirement: 問題の表示
**Reason**: 「タイトル画面」と「問題画面の表示」に置き換える。開いた直後の画面が第 1 問からタイトル画面に変わったため。
**Migration**: 開いた直後の表示は「タイトル画面」、問題の表示内容は「問題画面の表示」を参照する。

### Requirement: 前後の問題への移動
**Reason**: 「前後の画面への移動」に置き換える。第 1 問の前にタイトル画面が入り、第 1 問で前へを操作できるようになったため。
**Migration**: 移動の規則は「前後の画面への移動」を参照する。
