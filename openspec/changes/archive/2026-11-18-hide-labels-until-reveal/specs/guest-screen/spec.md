# Spec Delta

## MODIFIED Requirements

### Requirement: 正解情報を表示しない
参加者画面は、ラベル・正解の印・順位・銘柄・価格・解説、および正解発表の操作を表示してはならない（MUST NOT）。ラベルの帯、ラベルを持つ属性、ラベルを含む代替テキストも画面に置いてはならない（MUST NOT）。

#### Scenario: どの問題でも正解情報が表示されない
- **WHEN** 参加者画面で第 1 問から最終問まで順に表示する
- **THEN** どの問題でも正解の印・順位・銘柄・価格・解説が表示されない

#### Scenario: どの問題でもラベルが表示されない
- **WHEN** 参加者画面で第 1 問から最終問まで順に表示する
- **THEN** どの選択肢の要素にもラベルの帯（`.label-bar`）と `data-label` 属性がなく、写真の代替テキストがラベル（`選択肢 A` の形）を含まない

#### Scenario: 正解発表の操作がない
- **WHEN** 参加者画面を表示する
- **THEN** 正解発表のボタンは存在せず、Space キーや Enter キーを押しても正解情報は表示されない

### Requirement: 参加者に届くデータに正解情報を含めない
参加者画面を表示するためにブラウザへ届くデータ（HTML、JavaScript、画面のデータ取得の応答）は、どの選択肢のラベルも、どの問題の `rank`・`name`・`price`・解説も含んではならない（MUST NOT）。

#### Scenario: 参加者画面を進める間に受け取る応答に正解情報を含まない
- **WHEN** 参加者画面を開き、第 1 問から最終問まで順に表示する
- **THEN** その間にブラウザが受け取ったどの応答にも、問題セットのどの選択肢の銘柄・価格の文字列も、どの問題の解説の文字列も含まれない

#### Scenario: 参加者に届くデータの選択肢は順位を持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** どの選択肢も写真と選択肢の説明だけを持ち、`rank` を持たない

#### Scenario: 参加者に届くデータの選択肢はラベルを持たない
- **WHEN** 参加者画面が表示に使う問題データを取り出す
- **THEN** どの選択肢も `label` を持たない

#### Scenario: 参加者画面の HTML に正解情報を含まない
- **WHEN** 参加者画面の HTML を取得する
- **THEN** HTML には、問題セットのどの選択肢の銘柄・価格の文字列も、どの問題の解説の文字列も含まれない

#### Scenario: 参加者画面が読み込む JavaScript に正解情報を含まない
- **WHEN** 参加者画面が読み込むすべての JavaScript を取得する
- **THEN** そのどれにも、問題セットのどの選択肢の銘柄・価格の文字列も、どの問題の解説の文字列も含まれない

### Requirement: スマホでの表示
参加者画面は幅 360px のスマホで、横スクロールなしに表示できなければならない（MUST）。

#### Scenario: 幅 360px で横スクロールが発生しない
- **WHEN** 幅 360px のビューポートで 3 択の問題を表示する
- **THEN** ページの横スクロールは発生せず、全選択肢の写真と選択肢の説明が縦スクロールで見られる

### Requirement: 問題画面の表示
参加者画面は現在の問題について、問題番号と総問題数、問題名、説明、各選択肢の写真と選択肢の説明を表示順に表示しなければならない（MUST）。

#### Scenario: 第 1 問を問題番号つきで表示する
- **WHEN** タイトル画面から第 1 問へ進む
- **THEN** 第 1 問の問題名・説明・全選択肢の写真と選択肢の説明が表示順に、および「1 / 総問題数」が表示される

#### Scenario: 3 択の問題で 3 つの選択肢を表示する
- **WHEN** 選択肢が 3 個の問題を表示する
- **THEN** 3 つの選択肢が、問題データに書いた順に写真と選択肢の説明つきで表示される
