# Sharpen

## Request

> 格付けチェック用のWebアプリを作りたいです。

対話で確定した前提（ユーザー回答の要約）:

- 結婚式の二次会で使う。会場は明るいまま。
- 現物も出すが、参加者の手元（スマホ）でも確認できるようにしたい。手元に出すのは問題名・説明・選択肢の写真。音声は使わない。
- 投票・ランク判定は MVP ではやらない。司会画面と参加者画面は同期しない。
- 選択肢は 2〜3 個。正解発表では解説も出したい。
- 正解は参加者側ページから見えなくてよい（段階 1: 参加者向けデータから正解を除く）。司会画面 URL の秘匿は MVP では気にしない。
- 問題はリポジトリ内のファイルに 1 セットだけ書く。参加者は前へ / 次へで順に進む。
- TanStack Start で作り、Cloudflare にデプロイする。
- 見た目はゲーム風のドット調。味道園の看板の緑と赤系を使う。モックアップ（`mockup.html`）の方向で確定。
- 投影画面の中に前へ / 次へ / 正解発表を置く。
- 「全部当てる」形式（全選択肢の順位を当てる）は未確定。

## Sharpened

結婚式二次会の格付けチェックで、現物の出題を補助する Web アプリの MVP を作る。

- **問題データ**: リポジトリ内の 1 ファイルに 1 セットだけ書き、スキーマで検証する。
  - 問題: `mode`（`pick` = 最も高いものを 1 つ当てる / `order` = 全選択肢の順位を当てる）、問題名、説明、解説、選択肢 2〜3 個。
  - 選択肢: ラベル（A/B/C）、写真、順位 `rank`、銘柄 `name`、価格 `price`。`pick` の正解は `rank: 1` の選択肢。
  - 写真のファイル名は正解を推測できない名前にする（例 `q1-a.jpg`）。
- **司会画面（投影用 16:9）**: 問題名・説明と選択肢の写真を大きく表示する。画面内のボタンとキーボード（← / → / PageUp / PageDown / Space / Enter、プレゼン用リモコン対応）で前へ / 次へ / 正解発表を操作する。正解発表で正解の印、各選択肢の銘柄・価格（`order` では順位も）、解説を出す。全画面表示に対応する。
- **参加者画面（スマホ）**: 問題名・説明と選択肢の写真を前へ / 次へで順に見る。司会画面とは同期しない。
- **正解の秘匿（段階 1）**: 参加者画面に届くデータ（HTML・JS バンドル・loader の戻り値）に `rank`・`name`・`price`・解説を含めない。問題ファイルはサーバー側（またはビルド時）でのみ読み込む。
- **見た目**: クリーム地 × 味道園グリーン × 赤のドット調（DotGothic16）。明るい会場のプロジェクタで読めること。正解は色だけでなく印と文字でも示す（赤緑の色覚対応）。特定のゲームや番組の意匠は真似しない。参照: `openspec/changes/kakuzuke-mvp/mockup.html`。
- **技術**: TanStack Start、Cloudflare Workers へデプロイ。SSR か静的な事前レンダリングかは design で決める。
- **範囲外**: 投票、ランク判定、音声、管理画面、司会画面の URL 秘匿、画面同期、複数の問題セット。

未決定（ユーザーが決める）:

- `pick` と `order` のどちらを MVP に入れるか（データ構造は両方に対応しておく）。

## Current System

アプリのコードはまだない。新規に作る。

- リポジトリにあるのは OpenSpec の設定のみ。`openspec/config.yaml:1` で既定スキーマが `pstackspec`、`openspec/config.yaml:3-6` で成果物を日本語で書く設定。
- `package.json` はない。ローカル環境は Node v22.23.4 と pnpm 10.32.0。`wrangler` は未インストール。
- 画面の参照実装は `openspec/changes/kakuzuke-mvp/mockup.html`（素の HTML/JS）。データ構造（`mode`・`rank`・`name`・`price`）と参加者向けの射影 `toPublic` の形はここで試した。

## Done Means

- 問題データのスキーマテスト（Vitest）が、正しいデータで通り、壊れたデータ（`rank: 1` がない・重複する、選択肢が 1 個や 4 個、写真ファイルが存在しない）で失敗する。
- 参加者向けのデータに `rank`・`name`・`price`・解説が含まれないことをテストで確認する（loader の戻り値と、ビルド成果物のクライアント JS の両方）。
- Playwright の E2E で、司会画面を最初から最後まで進め、各問題で正解発表ができる。参加者画面も最初から最後まで進められる。キーボード操作でも同じことができる。
- Cloudflare にデプロイした URL を、プロジェクタ（明るい部屋）とスマホ数台の実機で最後まで進めて確認する。
